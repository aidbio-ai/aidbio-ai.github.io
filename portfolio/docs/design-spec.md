# Design specification

Canonical upstream: `matiollipt/aidbio-design-system`.

This portfolio intentionally implements the *design logic* rather than copying prototype internals.

## Visual grammar
- Humanist, warm display typography
- Clean scientific body typography
- Monospace for data/citation metadata
- Eight-hue synesthetic spectrum
- White/cloud neutral surfaces
- Ink/graphite text
- ~18px card radius
- Fibonacci spacing rhythm
- Soft, cool elevation
- Network/node motifs used to represent biology as graph structure

## Narrative color progression
- mechanism: blue/emerald
- networks: emerald/magenta
- data: indigo/orange
- models: indigo/magenta
- software: full spectrum
- AidBio synthesis: full spectrum + infinity identity

## Interaction
- Static-first
- Minimal JS
- No decorative infinite animation
- reduced-motion respected
- 44px minimum primary action height
