# Narrative architecture

## Core claim
AidBio exists because the founder's scientific problems progressively expanded in scale while preserving the same reasoning method.

## Tutorial progression
1. Mechanism — understand interacting signals before prediction.
2. Networks — represent many relationships explicitly.
3. Data — preserve biological identity and provenance as scale increases.
4. Models — encode biological structure into machine-learning representations.
5. Software — make analyses reusable, testable and inspectable.
6. AidBio — integrate these layers into decision-support systems.

## Portfolio page
A seventh, non-numbered page (`pages/07-portfolio.html`) sits outside the six-chapter progression. It exists to show the same method transferred to client-facing domains (agriculture, oncology, biomedical engineering) without turning the numbered tutorial into a résumé. It links back into Chapters 04–06 rather than duplicating their content.

## Editorial rule
Every historical item answers: **what did this stage teach that AidBio now operationalizes?**

Avoid:
- chronological résumé dumping;
- generic AI hype;
- lists of tools without scientific purpose;
- claims that an LLM replaces scientific judgment.
