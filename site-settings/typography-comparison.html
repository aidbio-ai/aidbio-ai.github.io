Typography audit · 29 October 2026 · Local working copy of aidbio.org. “Before” records the stylesheet before this update; “suggested” is the scale now applied to shared site CSS. Values below are CSS pixels at a 16px browser default.

Recommendation: 18px body / 20px introductions / 32px section headings / 16px controls / 14–16px supporting text. Keep paragraphs near 60–70 characters and use 1.6 line height for reading. Larger text and clear hierarchy support scanning; faster understanding has not been measured on AidBio.

Why this combination

  • GOV.UK type scale: 19px body, 24px large body and 16px small body, with distinct heading levels. AidBio’s 18/20/32 combination is an adaptation, not a prescribed standard.
  • USWDS typography: account for typeface, line length, line height and alignment together. Use left-aligned prose and a constrained reading width.
  • W3C resize text: text must support enlargement to 200% without loss of content or function. Relative sizes help; they do not prove conformance.
  • W3C reflow: ordinary text should reflow at 320 CSS pixels. Figures and data tables need separate handling.
