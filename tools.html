Software

Tools with a scientific purpose.

Availability and interfaces vary. A research application, a public library, and a sample report are different kinds of deliverable.

Public Python package

AidWeather

Retrieves and caches NASA POWER weather and solar-radiation data for points, transects, and regions. Includes a Python API and CLI.

NASA values follow the native source grid. Nearby coordinates may share a series.

Repository and documentation →
pip install aidweather
Sample available · Workspace application

AidWeather Report

Produces portable weather dashboards with charts, methods, and print-oriented assets, built on AidWeather.

The report application is a workspace package, not a PyPI distribution. A sample is publicly inspectable.

Research application

AidFarm

Organizes structured agricultural data, exploratory analysis, figures, evidence records, and reports. Workflows are configured for the project.

Client data stay private. Public demonstrations use explicitly labeled synthetic data.

Research application

AidCistrome

Connects raw SRA reads, quantification, reviewed DESeq2 design, gene sets, and promoter-motif analysis. A public ABA/iCB study shows the analysis from samples to interpretable outputs.

Profiles and experimental designs require review. Motif enrichment supports regulatory hypotheses; it does not demonstrate binding.

ABA and iCB figure story →
Public research repository

Aid2GO

Combines protein representations, similarity networks, and the Gene Ontology hierarchy to investigate protein function. Saved outputs can be explored in a local gallery.

Predictions are not experimental annotations. Internal evaluation and full-graph exploration have different scopes.

Repository and documentation →
Research application · Local first

AidWiki

Builds linked Markdown knowledge from registered sources. Claims are connected to evidence records and source locators; quotations can be verified against the originals.

Generated synthesis remains derived knowledge. Uncertainty and conflicting evidence must remain visible.
