Open source

Tools you can read, run and reuse.

We release our own research software as open source, so you can see how every result is produced. AidWeather installs with pip. Aid2GO installs by cloning the repository and using uv.

Python · command line and libraryOpen source · Apache-2.0

aidweather

Gets daily or hourly NASA POWER weather and solar data for a single point, a line of points or a whole region. Results are cached locally in SQLite, so repeated queries do not hit the NASA servers again. It covers 18 parameters, including temperature, rainfall, solar radiation, wind and soil wetness.

It is in beta: the public interface is stable, but features may still be added.

pip install aidweather

aid2go

Predicts what a protein does, as Gene Ontology terms, across biological process, molecular function and cellular component. It combines protein language-model embeddings, protein similarity networks and the Gene Ontology hierarchy in a graph neural network, and keeps predictions consistent with that hierarchy.

One command runs the pipeline end to end, from downloading data to evaluation, and it reuses saved intermediate files so reruns are fast.

git clone https://github.com/matiollipt/aid2go.git
uv tool install ./aid2go
