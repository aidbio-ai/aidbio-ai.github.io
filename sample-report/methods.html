What this dashboard summarizes

The report describes daily environmental conditions for Jan 01, 2010 – Jul 30, 2026 at the configured coordinates. Available variables in this report include T2M, T2M_MAX, T2M_MIN, PRECTOTCORR, RH2M, WS10M, WD10M, ALLSKY_SFC_SW_DWN, ALLSKY_SFC_PAR_TOT, VPD, GDD, CUM_GDD.

Missing variables are omitted rather than estimated.

Data retrieval

NASA POWER observations are fetched through AidBio’s aidweather application. The report preserves the requested location, period, parameters, and retrieval result as the basis for every metric.

Environmental metrics

VPD
Atmospheric drying demand; higher values can indicate greater plant water stress.
Precipitation
Accumulated rainfall during the report period.
Humidity
Relative atmospheric moisture.
Soil wetness
NASA POWER modeled wetness indicators where available.
Stability score
A transparent composite of available stress signals, not a crop-yield prediction.

Crop thermal accumulation

Crop-specific GDD uses daily max(((Tmax + Tmin) / 2) − base temperature, 0) with literature-based representative defaults for soybean, sugarcane/RB867515, Arabica coffee/Mundo Novo, sweet orange/Folha Murcha, and Mombaça pasture.

Without planting, emergence, flowering, or cutting dates, GDD describes thermal conditions during this report period only. It does not indicate developmental stage, maturity, remaining heat units, or harvest timing.

Historical comparison

When a complete location-specific climatology is available, the current thermal accumulation is compared with the historical distribution for the same calendar period. Percentiles describe substantially below normal, below normal, near normal, above normal, or substantially above normal.

If climatology is unavailable, the report shows measured accumulation and daily rate only.

AI summaries and limitations

AI text is grounded in computed statistics supplied to the summary model. It is a concise interpretation aid, not an independent measurement. If the local model is unavailable, a deterministic fallback is used. Always review the underlying charts and data coverage.

Location map

The map uses MapLibre GL JS with OpenFreeMap’s OpenStreetMap-derived style. It displays the configured point and never invents a field boundary. If coordinates or map tiles are unavailable, the report retains the coordinates and shows a neutral fallback.

For technical interpretation

Use the dashboard to identify patterns, compare the current period with a valid baseline, and decide what deserves field follow-up. Treat anomalies as departures from a reference distribution, not as automatic agronomic recommendations. Interpret every result alongside crop, soil, management, and observation context.
