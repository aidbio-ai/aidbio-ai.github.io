AidWeather

Weather history for any field, site or region.

AidWeather is an open-source tool that gets clean, cached weather and solar data from NASA POWER. AidWeather Report builds on it to produce a single page that shows the climate of a place.

Open source

AidWeather

  • One point, a line of points or a region, daily or hourly.
  • Local cache, so you do not download the same data twice.
  • Use it from the command line or from Python.
pip install aidweather

NASA POWER returns values for a grid cell, not for the exact coordinate, so nearby points can share one series. AidWeather documents the source and resolution of each parameter.

AidWeather Report

A weather report for your site

Give us a location and a period. You get a self-contained report with charts of temperature, rainfall, solar radiation and growing-degree days, plus a methods page that explains where each number comes from. It runs in any browser and can be printed.
