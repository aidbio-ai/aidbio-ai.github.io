Weather · Public Python packageAidWeatherRetrieve and cache weather and solar data with its source context attached.Explore⌄

AidWeather brings NASA POWER series into a documented Python or command-line workflow for points, transects, and regions.

A submitted coordinate resolves to a source grid cell. These are modeled or satellite-derived data, not measurements taken at that exact point.

Install
pip install aidweather
uv tool install aidweather

Field season · Sample reportAidBio Weather ReportTurn a site's weather history into a report you can explore and cite.Explore⌄

AidWeather Report turns public climate series into a portable dashboard with plots, notes, methods, and print views.

This sample covers a rainfed maize season near Jaguariúna, Brazil, from 18 February to 5 July 2022. Grid weather describes climate context, not on-site observations or a treatment effect.

AidWeather Report is a workspace application; this published sample is available to inspect.

Field trials · Research applicationAidFarmOrganize field observations, experimental units, figures, and evidence.Explore⌄

AidFarm helps structure agricultural data and produce inspectable analysis and reporting for a reviewed project workflow.

The plot uses AidFarm's 12-row example fixture. Every value is invented; it illustrates how individual plots stay visible and supports no agronomic conclusion.

Gene expression · Research applicationAidCistromeTrace a reviewed RNA-seq design from samples to genes and pathways.Explore⌄

The featured public study asks how ABA and iCB-treated Arabidopsis seedlings each differ from a DMSO control.

The two contrasts share a control. Similar patterns are descriptive; this analysis does not include a formal ABA-versus-iCB contrast.

Protein function · Public research repositoryAid2GOExplore protein similarity and Gene Ontology as testable predictions.Explore⌄

Aid2GO combines protein representations, similarity networks, and ontology relationships to investigate possible protein functions.

Network edges show computational similarity. Predicted terms are not experimental annotations; the saved evaluation is an internal protein-held-out test, not external certification.

Evidence across projects · Research applicationAidWikiKeep scientific claims connected to the sources that support them.Explore⌄

AidWiki helps build a curated, referenced library for each project. Teams receive that library with AidWiki to explore sources, review claims, and expand the knowledge base.

A generated synthesis remains derived knowledge. Uncertainty and conflicting evidence should stay visible.
